Constructor

Loads Monaco AMD loader and sets up instances. Sets original/modified models.
Options: host, original, modified, language, originalLanguage, modifiedLanguage, editorOptions
Tag:
<composite-monaco-diff>
Reads declarative diff scripts: text/original and text/modified.
Wrapper Component:
<MonacoDiff />
Wraps the custom element with dynamic ref forwarding and prop synchronization.
Method & Option
mgr.setTheme(theme)
options.editorOptions.theme
setMonacoTheme(theme)
Editor color theme. Global in Monaco: it changes every Monaco editor on the page, not only this one. The last value set wins for all of them.
Attribute:
theme
Built-in: vs, vs-dark, hc-black, hc-light. Any other name is passed to Monaco as is (themes registered with monaco.editor.defineTheme()); an unknown name logs one warning and Monaco shows vs. Removing the attribute changes nothing. Global, see the first column.
Prop:
theme
String, same values as the attribute. Global, see the first column.
Method & Options
mgr.setLanguage(lang)
options.language
Shared language. It applies to a side only when that side has no language of its own (next row). Default: javascript. Safe to call before whenReady().
Attribute:
language
Shared language. A side with <script lang> or a per-side property keeps its own language.
Prop:
language
String language prop (shared).
Methods & Options
mgr.setOriginalLanguage(lang)
mgr.setModifiedLanguage(lang)
options.originalLanguage
options.modifiedLanguage
Per-side language. Always wins over the shared language, at creation and on every later change. Pass undefined to hand the side back to the shared language.
Via declarative scripts:
<script lang="...">
Properties:
el.originalLanguage
el.modifiedLanguage 		Props:
originalLanguage
modifiedLanguage
Methods & Options
mgr.setOriginal(text) / mgr.getOriginal()
mgr.setModified(text) / mgr.getModified()
options.original
options.modified
Source texts to calculate diff for. Options and setters win over the declarative scripts. Setters are safe before whenReady() (the value is used when the editor is created).
Via declarative scripts:
<script type="text/original">
<script type="text/modified">
Properties:
el.original
el.modified
The scripts stay in the DOM. Other <script> children are ignored. The text cannot contain </script> - use the properties for such content.
Props:
original
modified
- Attribute of the scripts:
<script ... data-offset="3">
Optional, default 0. The common indentation of the script content is removed (so the HTML can be indented freely), then every non-empty line is indented by this many spaces. Must be a non-negative integer. The line break after the opening tag and the whitespace before the closing tag are not part of the content.

Methods & Option
mgr.setReadOnly(bool)
mgr.onChange(listener)
options.editorOptions.readOnly
The editor is a read-only viewer by default. With readOnly: false the modified side can be typed in; onChange reports edits made by the user (not programmatic setOriginal/setModified) with { original, modified } and returns an unsubscribe function.
Attribute:
editable
Event:
change
Boolean attribute. el.addEventListener("change", e => e.detail) gives { original, modified }.
Props:
editable
onChange
onChange({ original, modified })
Method
mgr.whenReady()
Resolves when the editor is mounted. Rejects when the declarative markup is wrong, Monaco could not be loaded, or the manager was destroyed (MonacoDiffDestroyedError).
Returns: Promise<{ monaco, editor, original, modified }> (the two last are the text models)
Method:
el.whenReady()
Event:
error
Always returns a promise: on an element that is not connected yet it stays pending until the element is connected and ready. A failed initialisation is also logged and dispatched as an error event (e.detail.error).
Access via forwarded ref:
ref.current.whenReady()
The ref is typed as MonacoDiffElement.
- Method:
el.getManager()
Returns underlying MonacoDiffManager instance. Throws while the element is not connected.
Returns: MonacoDiffManager
 Access via forwarded ref:
ref.current.getManager()
Methods
mgr.getEditor()
mgr.getMonaco()
Get Monaco editor instance and global Monaco API (null before ready - prefer the value whenReady() resolves with).
Access via manager:
el.getManager().getEditor() 		Access via manager from ref:
ref.current.getManager().getEditor()
Method
mgr.destroy()
Cleans up observers, disposes editor models, frees memory. Safe at any moment (also while Monaco is still loading) and more than once.
Lifecycle:
disconnectedCallback()
Moving the element inside the document keeps the editor. Removing it destroys the editor; text and per-side languages are remembered and restored when it is attached again.
Lifecycle:
Automatically handles component unmount cleanup.
Function
configureMonaco({ vs, timeoutMs })
Where Monaco is loaded from: one url or a list of .../min/vs base urls tried in order (self-hosting, pinning a version). Call it before the first editor is created. By default public CDNs (jsDelivr, unpkg, cdnjs) are tried in order, each with a 15 s timeout. Monaco is loaded through its AMD loader, which defines global require / define; a Monaco that is already on the page (window.monaco) is reused.
Same function, exported by the module:
import { configureMonaco } from ".../Module.js" 		import { configureMonaco } from "composite-monaco-diff"

Guide & Setup

The examples below use <center-and-height-resizer> (CenterAndHeightResizer.ts) to give the editor a resizable parent. It is a helper of the demos, not part of the npm package. Attributes: left, center, height. Events: onLeft, onCenter, onHeight (while dragging) and onResizeEnd (once per drag).
